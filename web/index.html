PatchFerret preview

Turn a mixing console show file into a patch list, a specification sheet and a wiring topology diagram.

Your show file never leaves this browser — parsing and PDF generation run locally in WebAssembly.
This is an early preview and very much still in development. Five console families are readable so far, and only partly: channel names and the input patch come through, while head-amp gain, bus sends and processing do not yet. Nothing it produces has been checked against a real console's own screens, and it cannot write or convert show files at all. Treat its output as a draft to check, not as paperwork to hang a show on.
